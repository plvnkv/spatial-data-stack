# Перший вхід і робота з GeoNode

## Відкрити портал

Підключіться до локальної мережі відділу й відкрийте `https://<geonode_host>/` у браузері. Візьміть точне ім’я з поля `geonode_host` у файлі `site.json`, який оператор використовував для розгортання. У зразку це `https://gis.example.internal/`. Це адреса запущеного порталу після налаштування внутрішнього DNS і TLS. GitHub містить код, конфігурацію та інструкції.

Виберіть **Sign in** і введіть дані свого облікового запису GeoNode. Під час першого запуску оператор входить як `admin` з початковим паролем із файлу `secrets/gis/geonode-app/ADMIN_PASSWORD`. Адміністратор створює іменні облікові записи працівників та додає їх до відповідних груп через панель адміністратора GeoNode. Для щоденної роботи використовуйте іменний обліковий запис.

## Знайти шар і зібрати карту

1. У каталозі відкрийте **Datasets** і знайдіть шар за назвою, ключовими словами або фільтрами.
2. Відкрийте картку шару. Перевірте попередній перегляд і метадані. Доступні дії залежать від прав облікового запису.
3. Відкрийте шар на карті. Для збереження власної карти скористайтеся розділом **Maps** або додайте шар до нової карти з його картки, потім збережіть карту під власною назвою.

## Опублікувати перший набір даних

1. Увійдіть як користувач із правом додавати набори даних. Виберіть **Add Resource → Upload Dataset**. Для першої спроби використайте [контрольний GeoJSON](../../tests/fixtures/sample-vector.geojson).
2. Додайте файл і запустіть завантаження. Коли обробка завершиться, відкрийте новий ресурс і перевірте, що він відображається на карті.
3. Відредагуйте назву, опис і метадані. У меню **Share** задайте права користувачам або групам. Перевірте результат під іншим обліковим записом.
4. Для растрового ресурсу порталу скористайтеся тим самим завантажувачем із тестовим GeoTIFF. Якщо потрібен окремий тайловий сервіс TiTiler, підготуйте COG і передайте його оператору для публікації.

## Використовувати GIS-сервіси з робочого місця

| Сервіс | Як відкрити |
| --- | --- |
| GeoServer | Для шару GeoNode візьміть точну адресу OGC-сервісу й назву шару з картки ресурсу. У QGIS створіть підключення WMS/WMTS або WFS за цією адресою. Для захищеного шару використовуйте підтримуваний спосіб автентифікації клієнта. |
| Martin | Відкрийте `https://<martin_host>/catalog`, щоб побачити джерела векторних тайлів. Для MapLibre використовуйте шаблон `https://<martin_host>/<source>/{z}/{x}/{y}`. |
| TiTiler | Відкрийте `https://<titiler_host>/catalog` для списку ID растрів. Шаблон XYZ — `https://<titiler_host>/cog/tiles/WebMercatorQuad/{z}/{x}/{y}.png?asset=<asset-id>`. |

Шари з GeoNode публікуються через GeoServer. Публікацію в Martin або TiTiler оператор додає окремо за [runbook публікації](02-publish-and-verify.md). Спільні тайлові каталоги доступні працівникам у LAN. Права **Share** застосовуються в GeoNode та пов’язаному GeoServer. Працівники звертаються до PostGIS через GIS-сервіси.

## Якщо портал недоступний

Якщо DNS-ім’я не відкривається або браузер не довіряє сертифікату, передайте оператору точну адресу й повідомлення браузера. Оператор перевіряє внутрішній DNS, довіру до CA та готовність застосунків за [runbook розгортання](01-deploy-from-scratch.md).
